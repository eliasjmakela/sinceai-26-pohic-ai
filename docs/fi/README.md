# Team working material (Finnish, not a deliverable)

The team's Finnish documents from the hackathon, kept for reference: the first business-case draft
(`OpenWeight.pdf`, built from `template.html` by `build_pdf.py`), its appendix `LIITE_perustelut.md`, a video script
draft, the team papers `PROJECT.md`, `PLAN.md`, `TIIMILLE.md`, and the cash-flow scripts in `analysis/`.

**Superseded.** Written before the decisions of 7 Nov evening. Where these files differ from `MASTER.md` §B–§C,
`PRODUCT.md` or `docs/`, those win. Main differences: the H7 self-lift on every new COMBI at €1,000 (not rails on
~10 % plus a virtual scale); €30 per device per month with NPV +€0.18 M, payback year 9; information gap ±37 % vs
±10 % (not 21 % / 9 %); no "verified weight"; no invoice upload; OpenWeight never relays offers. The list of needed
fixes to the PDF is `reviews/OPENWEIGHT_PDF_FIXES.md`.

The deliverables are in `docs/` (English) and `part1/`; the demo is `app/`.
