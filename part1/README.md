# part1/: weighing concept (OpenWeight, challenge Part 1), v2

The deliverable is **`WEIGHING_CONCEPT.md`** (v2, 7 Nov: H1 hopper-stage plate + H2 fleet self-calibration,
full installed cost per device; H7 hydraulic self-lift added as the team idea to explore, §19). Everything else here supports it.

## Setup

```bash
python3 -m venv part1/.venv            # tested with Python 3.14.4
part1/.venv/bin/pip install -e /path/to/resources/Europress_SMART_Material_Value_Engine_v1.0.1 -r part1/requirements-lock.txt
```

## Reproduce every number and figure (one command)

```bash
part1/scripts/reproduce.sh [<kit>/data/competition/public]
```

Order: `calc/` (no data) → `charge_sum`, `self_calibration`, `fusion` (synthetic data, fixed seeds) → `tiers.py`
(reads `installed_cost.json` and `self_calibration.json`) → v1 analyses and figures → `check_interface.py`, which
fails the run if `WEIGHING_CONCEPT.md` no longer contains the generated tables verbatim. Scripts read only
`data/<profile>/public` through `europress_data.sdk.open_dataset`. Two runs give byte-identical outputs.

To change an assumption, edit `calc/h1_params.py` (H1 error model) or `calc/installed_cost.py` (cost lines), re-run
the command and paste the changed `generated/*.md` tables into the concept; the check enforces it.
