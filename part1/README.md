# part1/: weighing concept (FullLoad, challenge Part 1)

The deliverable is **`WEIGHING_CONCEPT.md`**. Everything else here supports it.

| Path | What it is |
|---|---|
| `WEIGHING_CONCEPT.md` | The concept: principle, COMBI/DUO placement, BOM, installation, calibration, error budget, validation plan, limitations, T0/T1/T2 comparison, brief coverage, references, human-review list |
| `sigma_tiers.json` | Interface for the app (shape in `briefs/PART1_WEIGHING.md` §4). Generated by `scripts/tiers.py` |
| `figures/placement.svg` | Hand-drawn SVG placement sketch (its own source) |
| `figures/error_budget.svg`, `accuracy_value.svg`, `drift_watch.svg` | Generated by the scripts |
| `generated/` | Script outputs (tables and JSON) quoted in the concept |
| `scripts/` | `tiers.py` (tier parameters and error budget, the single source of truth), `accuracy_value.py` (adapted from the kit's `examples/weighing_accuracy_value.py`), `drift_watch.py` (ticket cross-check), `check_interface.py` (QG6 check), `reproduce.sh` |
| `THIRD_PARTY_part1.md` | Rows to merge into the root `THIRD_PARTY.md` |
| `GATES_REPORT.md` | Self-check against the quality gates |
| `requirements-lock.txt` | Exact package versions in `part1/.venv` (plus the editable starter kit) |

## Setup

```bash
python3 -m venv part1/.venv            # tested with Python 3.14.4
part1/.venv/bin/pip install -e /path/to/resources/Europress_SMART_Material_Value_Engine_v1.0.1 matplotlib
```

The starter kit pulls in duckdb, numpy, pandas, pyarrow, PyYAML and tabulate. `requirements-lock.txt` lists the
exact versions.

## Reproduce every number and figure (one command)

```bash
part1/scripts/reproduce.sh [<kit>/data/competition/public]
```

The data root defaults to `$FULLLOAD_DATA`, or else to the competition package in the main checkout. The scripts
read only `data/<profile>/public` through `europress_data.sdk.open_dataset` and refuse any other path. The output is
deterministic: seed 1, sorted SQL, and matplotlib's `svg.hashsalt` fixed with no date metadata. Running the command
twice gives byte-identical files under `generated/`, `figures/` and `sigma_tiers.json`. The last step,
`check_interface.py`, fails the run if `WEIGHING_CONCEPT.md` no longer contains the generated tables verbatim.

To change a tier's σ or cost, edit `scripts/tiers.py`, re-run the command, and paste the new
`generated/tiers_table.md`, `error_budget.md` and `accuracy_summary.md` into the concept. The check enforces this.
